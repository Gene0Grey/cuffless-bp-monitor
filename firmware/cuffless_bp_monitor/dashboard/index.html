    1. Heart rate is computed in this browser from the ECG R-peaks, as the median of the last 8 beats.
    2. Pulse transit time runs from each ECG R-peak to the foot of the pulse at that site (intersecting-tangent method), as the median of the last 8 beats. It includes sensor and filter delay, so compare sites and watch trends rather than reading absolute values. No blood-pressure value is shown until per-person calibration exists.
    3. PPG traces are the infrared channel, drawn inverted so each pulse rises. Recordings keep the values exactly as the board sends them.
